# План и состояние проекта

Это «память» проекта для следующего ассистента или разработчика.
**Закрыли задачу — отметьте её здесь в том же коммите.**

_Состояние на 18 сентября 2026._

---

## Сделано

**Бэкапы.** Скрипты копии, проверки и восстановления базы; проверены на живой
базе. Ночная копия в 03:30. Шифрованная отправка копий в хранилище S3 —
код готов и проверен, но само хранилище ещё не настроено (см. ниже).

**Сервер.** Timeweb VPS, домен `codegolf.ru`, HTTPS, служба сайта, nginx,
firewall, подкачка. Установка с нуля — [server-setup.md](server-setup.md).

**Честность соревнования.** Решение больше не видит данных тестов: раньше
`test["expected"]` проходил любую задачу. Скрытые тесты действительно скрыты.
Регрессионная проверка `npm run test:sandbox` стоит в предеплойных проверках.
На боевом раннере подтверждено: честное решение проходит, списывание — 0 тестов.

**Вход через Stepik** работает. Исправлены кука сессии и подбор свободного ника.

**Продуктовые улучшения** — подробно в [product-stage4.md](product-stage4.md),
там они названы «этап 4». Очки за укорачивание решения и за первое место,
уведомления «рекорд побит», цель по длине, история попыток, подсчёт зачёта
соревнований, публичные страницы участников с картинкой для соцсетей.

**Устойчивость:**

- деплой больше не затирает правки задач из админки;
- структура базы меняется миграциями;
- Python 3.11 и в браузере, и в раннере;
- сайт не стартует без адреса раннера;
- у зависших проверок не больше 3 попыток, у запасной проверки — 15 секунд на всё;
- IP посетителя нельзя подделать заголовком;
- Next.js 15.5.25: закрыты критические уязвимости;
- инструкции по мониторингу и восстановлению из хранилища.

## Известные ограничения и технический долг

- **`postcss` внутри Next** — уязвимость только при сборке, с собственными стилями
  проекта. Лечится переходом на Next 16 (мажорное обновление).
- **Очередь проверок и лимиты живут в памяти процесса.** На одном сервере
  это работает. Для нескольких серверов нужны Redis и отдельный воркер.
- **Pyodide 0.24.1 устарел.** Обновление = смена версии Python везде
  (правило 3 в [AGENTS.md](../AGENTS.md)). Python 3.12 дал бы удобные
  для кодгольфа f-строки (PEP 701).
- **Скрипты хранилища S3 проверены с подменой хранилища.** На настоящем —
  после настройки.
- Нет подтверждения email и сброса пароля; уведомления — только на сайте,
  без почты и Telegram.
- Мёртвый код: `src/lib/mock-data.ts`, дубль `validateOneliner`
  в `src/lib/python-serializer.ts` (рабочий — в `src/lib/utils.ts`),
  стили `.monaco-editor` в `src/app/globals.css`.
