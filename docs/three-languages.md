# Арена на трёх языках: Python, JavaScript, C#

_Решение владельца от 22–23 сентября 2026. Пробу C# не ждём: людей на арену
будет приводить курс на Stepik._

Этот документ — план перехода. Текущее состояние по пунктам — в
[ROADMAP.md](ROADMAP.md), устройство и правила — в [AGENTS.md](../AGENTS.md).

## Принятые решения

| Вопрос | Решение |
|---|---|
| Языки | Python, JavaScript, C#. Python уже готов, JS и C# доводим до ума вместе |
| Название | **Арена однострочников** — одно имя везде. «Arena Oneliners» и «Python Code Golf» убрать |
| Рекорды | У каждой задачи три таблицы рекордов — по языку. Длину между языками не сравниваем |
| Очки | Начисляются в каждом языке отдельно по одним правилам: решил задачу на Python — очки, решил её же на JS — ещё очки |
| Рейтинги | Четыре: Python, JavaScript, C# и общий, где очки складываются |
| Сервер | 2 ядра / 4 ГБ (увеличен 23 сентября). Отдельный сервер под раннер — позже, если понадобится |
| Вход | Пока остаются оба способа. Вход по почте без восстановления пароля — известная проблема, записана в ROADMAP |
| Новая платформа | Новый внешний вид и правила поверх нынешнего ядра, **не переписывание с нуля** |

## Этапы

**Этап 1. Фундамент** — идёт сейчас.

1. Раннеру отдано целое ядро и 1 ГБ памяти, C# собирается по два одновременно.
2. JavaScript (Node.js 20) в раннере. Защита от списывания как у C#: в программе
   нет правильных ответов, их сравнивает сервер; набор «атак»
   `npm run test:sandbox:js` гоняется перед каждой выкладкой.
3. Попытки и рекорды всех языков — в общих таблицах `submissions` /
   `best_submissions` с колонкой `language`. Очки, место, «рекорд побит» считаются
   для каждого языка отдельно.
4. Четыре рейтинга, очки по языкам в профиле, переключатель языка на странице задачи.

**Этап 2. Задачи.** Один формат задачи для трёх языков с эталонным решением;
автоматические тесты (сервер сам придумывает входные данные); усиленная проверка
рекорда; проверка задач заведомо неправильными решениями; 40–50 задач к запуску
с переписанными условиями; перепроверка старых рекордов.

**Этап 3. Дизайн и название.** Макеты пяти экранов в двух стилях → выбор владельца →
перенос на сайт. Мелочи из разбора 22 сентября: почта в подвале на несуществующем
домене `arena-oneliners.ru`, название дважды в заголовке вкладки, «2 участников»,
английские слова (Bronze/Silver/Gold, «Лидерборд», «сабмит»), пустые витрины.

**Этап 4. Подготовка к курсу.** Ссылки из уроков Stepik на задачи, таблица потока
курса, счётчик посещений и сбор ошибок, нагрузочная проверка, автопроверки на
GitHub, закрытие пунктов владельца (копии базы вне сервера, мониторинг, пароль).

**Этап 5. Запуск.** 10–20 человек из курса, неделя наблюдений, потом весь курс.
